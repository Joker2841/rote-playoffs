SCOPE
  Read-only. It reads PATH, stats files, and parses the text of shell
  startup files without ever sourcing them. Nothing is changed and no
  command is repaired. A line assigning a secret-looking name is
  reported as present but never echoed. Results describe the PATH of
  the shell that invoked it, which is why a login shell and an editor
  terminal can legitimately disagree.
