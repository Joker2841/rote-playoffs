HOW TO RECLAIM, IN THIS ORDER
  Freeing space inside does not shrink the Windows file. Compacting
  before freeing reclaims almost nothing. Do both, in this order.

  1. free it inside the distro
     ~ review ~/.cache; it is safe to clear but tools will rebuild
     pip cache purge
     sudo journalctl --vacuum-size=200M
     sudo apt clean
     (lines marked ~ are judgement calls, not routine cleanup)

  2. then hand the freed space back to Windows
     wsl --manage Ubuntu-24.04 --set-sparse true      (from Windows)

  3. docker keeps its own disk, handled separately
     docker system df          see what is actually live
     docker system prune       free it inside docker's disk
